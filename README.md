# Правовые документы Flashgram

Русскоязычный статический сайт с условиями использования и политикой конфиденциальности Flashgram. Публикуется через GitHub Pages из корня ветки `main`.

Тексты написаны для Flashgram самостоятельно после изучения [условий Telegram](https://telegram.org/tos) и [политики Telegram](https://telegram.org/privacy). Они не являются переводом документов Telegram и не утверждают, что Flashgram принадлежит Telegram.

При существенных изменениях функций или практики обработки данных обновляйте тексты и дату редакции.
